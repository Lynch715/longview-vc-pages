# 远见资本 · v0.28.1

[打开游戏](https://lynch715.github.io/longview-vc-pages/)

从 1990 年连续经营至 2050 年。六板块上市、ABS 风险联动、六个新增赛道与上市后资本操作，现加入真实按月经营和独立季度损益。财报展示收入、成本、利润及三类现金流，年度直接汇总季度；所有条款和结果均为游戏模拟。

本版经财务、股份、贷款、清算、上市审核和存档兼容审计。沿用原站点与存档入口，升级前保留不可覆盖的原始备份，旧年报、现金、持仓、交易和收益榜保留。无需新开基金。

本仓库仅提供公开运行资源。制作人：大老师 · 微信：lynchrrr。

企业经营失败后，可在清算前追加投资尝试抢救，成功率 8%—30%；成功后收缩经营，失败后按实际资产清算。确认前完整列示费用与风险，旧存档、历史回款及榜单保持兼容。
