# 远见资本 · v0.31.0

[打开游戏](https://lynch715.github.io/longview-vc-pages/)

从1990年连续经营至2050年的中文风险投资经营游戏。所有财务参数、条款、政策与经营结果均为游戏模拟，金额单位为万元。

本版加入季节、政策和市场事件、消费业务广告宣传、逐月推进与最近12个月经营复盘。广告可查看推广前后实际收入、利润和客户变化；变化还受经营与竞争影响，不保证回本。

推进季度或全年时，遇到认购权即将到期、偿债现金偏紧、经营危机或年末退出报价将失效，会先暂停提醒。处理后可继续剩余月份；尚未处理时需知悉后明确选择继续。

同时合并批量分红交互修复：统一比例修改后须应用或撤销，保留单家公司微调，防止过期确认重复办理。原有收购、分红、追加投资抢救、后续轮次融资、IPO与上市后资本操作保留。

沿用原站点、存档主键及version 10。历史资金、股份与报表不回算；旧广告参数保留，旧季度报表不拆成虚构月份。无需新开基金，换设备前请导出备份。
