# 远见资本 · v0.29.0

[打开游戏](https://lynch715.github.io/longview-vc-pages/)

从 1990 年连续经营至 2050 年。六板块上市、ABS 风险联动、六个新增赛道与上市后资本操作，按月经营并披露独立季度损益。所有条款和结果均为游戏模拟。

v0.29.0 加入清算前主动增资施救：自填金额、按危机估值取得新股，补足经营欠款、清偿到期和违约本金，余款支持恢复经营与未完建设。经营失败后的抢救成功率仍为 8%—30%，失败会清算，已清算企业不能复活。

同一家公司可按经营里程碑，主动发起 Pre-A、A、B、C 至 Pre-IPO 后续融资。每轮至少间隔十二个月并有市场承接；外部募资一次进入公司，基金再决定是否跟投，资金与股份不重复结算。

沿用原站点、存档主键与 version 10。历史资金、股份及报表不回算，无需新开基金；季度分红存档修复和小字可读性调整保持。存档仅保存在当前浏览器，换设备前请导出备份。
